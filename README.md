Cab Invoice Generator
A Java TDD-based project that calculates cab fares and generates invoices for users.

Features
Single ride fare calculation
Multiple rides invoice summary
User-based invoice generation
Normal & Premium ride support

Fare Rules
Normal Ride: Rs 10/km, Rs 1/min, Min Rs 5
Premium Ride: Rs 15/km, Rs 2/min, Min Rs 20

Tech Stack
Java
TestNG
Git

Project Structure
Ride, RideType, CabInvoiceGenerator,
InvoiceSummary, RideRepository, InvoiceService

How to Run
Open project in IDE
Run CabInvoiceGeneratorTest

Concepts Used
Test Driven Development (TDD)
OOP & Clean Code
Service–Repository pattern
